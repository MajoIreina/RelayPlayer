# RelayPlayer v0.1.9

本版恢复 0.1.6 播放器界面和 Relay 自己的发现、浏览器授权及配对流程，并接入社区 DLSS 5 NR 运行时，修正 USB DualSense 的细微姿态输入，并调整 Windows 音频输出配置。公开下载包不包含个人主机、配对密钥或账号。

- **DLSS 5 NR**：从底栏或原画质面板启用 NR，下次连接应用。首次自动取得并校验社区运行时与固定版本模型，约 443 MiB；建议预留 1.5 GiB。无需运行第三方安装器。组件完好时复用；下载可取消，损坏后先验证新副本再保留旧目录备份。NR 默认使用 Vulkan/D3D12 桥接、输入分辨率、单次处理。兼容性以显卡、驱动与实际处理结果为准。窗口打开不代表 NR 已生效。
- **USB DualSense 体感**：启用 SDL 原生 PS5 HID、后台事件，避开缺少传感器通道的 RawInput。对两个固定运行时的本机配置副本应用可复核的[姿态补丁](../patches/dualsense-motion.patch)：移除会累积丢失小角度变化的四元数死区，保留物理加速度的重力参考。原版组件保持原样。此修正参考上游 [#777](https://github.com/chiaki-ng/chiaki-ng/issues/777) 与 [#805](https://github.com/chiaki-ng/chiaki-ng/pull/805)，不是 Sony 官方代码；#805 未合并，本版只采用上述范围，不宣称包含其所有改动。
- **音频**：在串流子进程使用 WASAPI；默认缓冲改为 16,384 字节（48 kHz 双声道 S16 约 85 ms），有效的自定义缓冲保留，旧的不规则值向上规范为兼容大小。也处理当前选中的独立配置。该调整减少输出端下溢的风险，代价是比原默认增加约 35 ms 缓冲；不保证消除网络丢包引起的杂音。Opus 解码算法未替换，不更改系统设备格式。
- **配对保留**：普通与 NR 模式沿用 v0.1.8 的 RelayPlayer 独立 Windows 用户配置。切换前先关闭原播放窗口。GitHub 资产仍只打包白名单源码、宿主和说明；运行时与专有模型按需取得，来源与限制见[组件声明](../../notices/CHIAKI-NR.md)。

验证：Rust 单元与进程集成检查、两种真实 Qt 运行时的隔离与设置迁移、实际四元数函数的小角度累积和反向回中、USB DualSense 无窗口后台传感器事件；RTX 5080 上 1080p 静止 24 帧与运动 40 帧 NR 输出有效。测试不使用个人 PS5 凭证，未完成 PS5/GT7 实机串流及音质听测，因此这些部分仍需在用户实际网络和游戏中确认。

使用：解压后运行 `RelayPlayer.exe`，从原来的「连接」面板完成发现、浏览器授权与配对，中央嵌入实际串流窗口。底栏音量、NR、全屏保留，F11 全屏只显示画面。后端仅通过指定主机的直接串流子命令启动，不打开管理首页。NR、分辨率、编码、帧率、最高 200 Mbps 目标值在下次连接应用；目标值不能保证主机实际输出。未接入的功能保留原位置并禁用。

新增验证：83 个内置协议测试（含本地发现/加密响应）、宿主模拟 PS5 完整 UDP/TCP 配对和 DPAPI 保存、授权回跳校验、损坏存储保护、注册表绑定与字节读回、直接串流进程参数及真实视频包状态识别。两种实际 Qt 运行时均读到了 Rust 写入的合成主机，并验证 200 Mbps 等参数和当前配置的映射。没有使用个人 PS5 凭证测试。仍未完成真实 PS5 串流画面与声音、GT7 体感验收。

新协议子集及宿主源码随源码包提供，采用 AGPL v3 并保留上游署名。此文件描述开发候选版本，不表示已发布 GitHub 资产。
