**Windows x64 版现在可以用网络连接 PS5，无需采集卡或手动安装播放后端。** 下载 `RelayPlayer-0.1.8-windows-x64.zip`，完整解压到可写目录，然后打开 `RelayPlayer.exe`，点 **配对 / 连接 PS5**。

- 首次自动从 chiaki-ng 官方 GitHub 下载约 113 MiB 的固定版本，校验后打开真实的发现、配对和播放窗口。之后复用本机组件；下载中断可以重试；识别出已有组件损坏时，会先验证新副本，再保留旧目录备份并恢复。如果有上游官方 ZIP，也支持 `--connect --backend-archive <路径>` 离线准备。
- 电脑和 PS5 请先连接同一局域网，在 PS5 的 **设定 → 系统 → 远程游玩** 启用远程游玩。选中主机；若按码配对，使用此处 **配对设备** 显示的码及本人的账号信息。没有发现主机时可以手动输入其局域网 IP。
- 默认网络模式使用 chiaki-ng 独立窗口，串流设置在该窗口调整。此后端不支持宿主嵌入、采集卡、DLSS5 NR 或保证实际码率；兼容 IPC 接口仍可显式启用。
- 包内没有已配对的 PS5、个人凭证或预设账号。已有旧版可以保留，首次使用本网络后端需要以自己的身份配对。

| 下载文件 | 用途 |
| --- | --- |
| `RelayPlayer-0.1.8-windows-x64.zip` | 普通 Windows 用户下载此包。 |
| `RelayPlayer-0.1.8-public-source.zip` | 此标签的 Rust 宿主、后端准备工具、图标与文档。 |
| `SHA256SUMS.txt` | 两个 ZIP 的 SHA-256，可用 PowerShell `Get-FileHash` 核对。 |

Windows x64 隔离测试已验证连接按钮可以拉起真实的 chiaki-ng 窗口；发现开关、F2 手动添加主机与配对表单的账户 ID、配对码和 PS5 选项均可操作。测试未输入个人信息、未提交配对，未用真实 PS5 测量画面、时延或手柄表现。

参阅 [chiaki-ng 的配对说明](https://chiaki-ng.github.io/chiaki-ng/setup/configuration/) 和 [PlayStation 的遥控游玩设置说明](https://www.playstation.com/zh-hans-cn/support/games/playstation-remote-play-on-pc-and-mac/)。v0.1.7 仍是首个发行版。
