基于 egui/eframe 等开源项目构建的 Windows PS5 播放器宿主。串流、采集与画质处理需要另配兼容后端。

**v0.1.7 是首个公开版本，发行内容为宿主及其源码。** Windows 用户可直接打开界面；要连接真实 PS5、显示 HDMI 输入或使用 NR/超分，还需适配相应能力的后端。公开包不提供播放后端或 GPU 运行库。

- 全屏播放时隐藏上下栏和侧边设置；窗口模式可自动收起顶栏。底栏提供音量、静音和 NR 开关。
- 目标码率为 2–200 Mbps。宿主区分请求值、后端反馈和帧统计；锁定目标不能保证实际传输码率。
- 初次启动使用自己的数据目录；不含预配对主机或个人授权。仅在原 Windows 用户显式执行 `RelayPlayer.exe --import-legacy` 时，才从相邻旧版导入缺失的数据。设置取自 0.1.5，加密授权优先取自 0.1.5，再回退至 0.1.4、0.1.3。
