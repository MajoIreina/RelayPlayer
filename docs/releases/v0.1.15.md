# RelayPlayer v0.1.15 local candidate

保留 0.1.6 UI 与 0.1.14 的窗口交接、画质应用、最近主机重连和直接停止，修正串流音频的累积延迟。

- 旧版默认 16,384 字节 S16 双声道设备缓冲，在 48 kHz 下对应约 85.3 ms；另有双倍 SDL 队列与八倍环形缓冲，积压时会进一步延后声音。
- Relay 串流改为音频设备回调直接拉取一个 PCM 环形缓冲，取消该路径的 SDL 排队和排队线程；请求 512 个采样帧，在 48 kHz 下约 10.7 ms。收到音频后预备 20 ms 数据，应用缓冲通常最多 40 ms；设备实际周期更大时按设备能力调整。
- 积压越界时只保留最新目标缓冲，超过 80 ms 未更新的数据在读取或追加时丢弃；缺音填零并重新预备，不反复播放旧声音。丢帧或缺音边界以 1 ms 渐变处理，正常 PCM 保持完整采样帧对齐，保留原来的 Opus 解码与网络丢包处理。
- Relay 专属配置自动将旧设备缓冲迁移为 2,048 字节；默认配置与当前选中配置都更新。授权和用户画质设置继续复用，不修改全局系统音频格式。
- 后端状态增加音频回调次数、实际缓冲、丢弃帧及缺音次数，仅报告应用队列和 SDL 周期，不将它们冒充扬声器端或 PS5 到耳机的总延迟。

验证：120,147 项音频断言覆盖多采样率、多声道、PCM 完整性、缺音、突发和两分钟虚拟时钟停顿。WASAPI 实际设备静音 PCM 测试运行 5 秒，回调周期 10.667 ms，缓冲峰值与上限 40 ms，470 次回调；主动模拟一次供音停顿后恢复，SDL 无第二级排队。本轮未中断用户正在运行的 PS5 串流，游戏实际听感需使用新版确认。

此版为本地候选；未上传或替换 GitHub 的 0.1.14。个人使用副本从 0.1.14 保留授权和设置，公开候选 ZIP 不包含 data 或个人凭证。
