# RelayPlayer v0.1.11 local candidate

修复关闭 Relay 播放器后仍有独立窗口显示画面的问题。

- 退出时先关闭本次播放会话，随后释放嵌入表面，避免将嵌入画面还原为独立窗口。
- 嵌入和独立播放均发送正常关闭通知；窗口未创建或组件不响应时，最多等待 750 ms，再清理本次播放进程和辅助进程。
- 每次播放使用独立的 Windows Job；宿主被强制结束时也清理受管理的播放组件，不按进程名结束其他软件。
- 自然结束会话时先清理辅助进程，再等待输出读取线程，避免继承输出管道导致退出卡住。
- 保留 0.1.6 界面及 0.1.10 功能。本地已配对主机与播放设置沿用 0.1.10，公开压缩包不含本地数据或凭证。

验证：43 项 Rust 单元检查通过（2 项环境/内部夹具检查默认忽略），进程协议集成检查通过。临时隐藏窗口覆盖独立和跨进程嵌入窗口正常关闭；另验证无窗口组件的超时清理、自然退出后的辅助进程清理、宿主强制终止、重复清理及其他进程不受影响。未操作用户正在运行的播放器，也未进行 PS5 实际串流退出验证。

这是本地工作区构建，尚未创建 Git 标签或上传 GitHub。串流、渲染和硬件限制沿用 [0.1.10](v0.1.10.md)。
