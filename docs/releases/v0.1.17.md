# 0.1.17 本地优化候选

基于 v0.1.16（787602a435b96a15d3605a007d03a9def99df9af）。本轮保留现有实时串流、解码与 GPU 渲染内核，借鉴 NEXT 的控制与媒体职责分离方式；没有引入第二层 Node 转发，也没有替换为 NEXT 的离线软件解码路径。此版本尚未对外发布。

## 本轮已完成

- 组件准备与 PS5 状态检查/唤醒并行。只有主机服务及完整运行时都就绪才启动串流；取消、失败或停止后不接受迟到的启动结果。
- 已存在的 relay-render 直接校验最终完整文件清单，省去额外读取 chiaki-nr 基础目录。首次安装仍走原始基础组件与新渲染覆盖包流程。文件缺失、同尺寸篡改均拒绝启动。
- 控制管道改为后台写入：32 条有界队列，连续待发送设置保留最后一次，PIN/设备操作维持顺序；停止优先。管道阻塞不再阻塞 UI 提交，仍保留 750 ms 退出宽限与进程树清理。
- 相同设置不再重复保存或发送；原生端重复命令只更新确认版本。修改颜色时不重置 NR 调节版本，不重建未变化的纹理滤镜与 ArtCNN；所有自定义效果中性时省去自定义滤镜。
- “微调颜色与质感”新增曝光度（-3 至 +3 EV）和亮度（-1 至 +1）。曝光度在当前色彩传递函数对应的线性光中乘以 2^EV；亮度使用原生色彩调节。默认均为 0，旧设置缺少这两项时保持原样。曝光度通过动态参数应用，无需重建纹理滤镜。
- 运行状态增加主机/组件就绪、串流启动、首视频信号时序及设置应用耗时/滤镜创建计数。首视频信号不是显示器实际出光时间；渲染提交耗时不是完整 GPU 或端到端延迟。

## 性能与验证范围

同机 Windows 热缓存，分别先预热一次，再各采样三次；测量包括 PowerShell 进程启动、校验与配置初始化，不包括主机唤醒、网络、真实视频帧或显示器延迟。

| 准备流程 | 三次样本中位数 |
| --- | ---: |
| 0.1.16：基础组件校验 + 最终组件校验 + 配置 | 3455.54 ms |
| 0.1.17：最终完整组件校验 + 配置 | 2011.92 ms |

本机该阶段减少 1443.62 ms（约 41.8%）。并行唤醒还可以重叠独立准备时间；实际收益取决于主机状态，未给出真实 PS5 首帧加速比例。

验证已通过：宿主 63 项（2 项原有忽略）、协议库 83 项、子进程生命周期与控制管道阻塞/退出检查、144 项补帧策略、120141 项确定性音频检查。GPU 像素回读覆盖 SDR、线性 HDR、HDR10 PQ 的正负曝光度和亮度；ArtCNN/FSR 真实 GPU hook 检查通过。原生集成检查覆盖设置资源复用、选择性重建、NR 调节版本及中性旁路。

界面已检查新增滑块及旧画质设置读取。没有自动连接真实 PS5，本轮没有新的实机帧率、网络尾延迟或主观音质结论。PCM 拷贝快路径、音频端点事件化、物理运行时进一步去重保留后续迭代，不能计为本轮收益。

## 使用与导入

个人候选目录可从 0.1.16 复制 data/public-connections.bin、data/public-playback.json、data/player.json；Windows DPAPI 授权仅能由原 Windows 用户解密。先关闭播放器再复制，保留旧版目录。新控制项缺失时自动为 0；无需重写既有画质设置。不要将个人 data 目录放入分发包。

本地包可用 tools/package_public.py 的 --source-ref 显式指定当前已提交的候选提交；默认正式打包仍要求版本标签。包内容来自 Git blob、固定白名单与锁定的原生清单，不读取个人 data。原生对应源码和更新补丁一并保留。
