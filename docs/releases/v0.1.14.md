# RelayPlayer v0.1.14

保留 0.1.6 播放器界面，调整 0.1.13 的视频窗口启动流程，并新增底栏一键连接最近主机。

- 白色的 Relay Video 标题栏来自后端顶层窗口，并非项目设置对话框。视频窗口现在先在隐藏状态创建，使用固定交接标记；Rust 同时校验所属进程、Qt 窗口类及标记后完成嵌入，再显示画面。视频交换链也在窗口曝光后创建，避免先最大化再改父窗口。退出和重连时恢复原先隐藏状态，禁止通过 WINDOWPLACEMENT 将隐藏窗口重新显示；结束会话也不再最大化原生窗口。
- 恢复 0.1.12 的画质设置应用时序：通过私有 stdin 在引擎初始化后应用一次，移除 0.1.13 会话建立前的重复 GPU 初始化。Relay 视频模式不再合成空白 Qt Quick 叠层，原生设置和菜单继续禁用。独立窗口仍由播放器的既有选项控制。
- 左下角播放按钮直接连接最近成功连接的主机；收到视频后才更新记录，失败尝试不覆盖记录。重启后保留主机选择与成功使用的连接地址。旧版未记录历史时，只有一台已配对主机则直接连接；存在多台或没有有效地址时打开原主机面板。连接中的按钮仍直接停止，不增加弹窗。
- 会话异常退出时传回固定错误原因，显示在播放器原有提示区域；不输出主机返回的敏感文本，不增加原生错误对话框。
- 保留补帧倍率上限修正、原生发现与菜单禁用、后台实体手柄输入及 USB 体感、音频缓冲修正、现有画质功能、真实状态、全屏隐藏控件、直接停止和退出进程清理。

验证记录：Rust 单元与进程集成测试；真实 Qt/Vulkan 窗口经生产嵌入代码交接；合成渐变画面经实际渲染路径读取 GPU 像素，576 个采样像素全部非黑，亮度范围 90；启动、嵌入及退出期间未发现可见原生顶层窗口。实机 PS5 在隔离授权副本中验证 1080p、约 60 fps 的连续串流和停止。0.1.13 的约 10 秒断开未能在隔离环境稳定复现，因此没有将其退出原因臆测为已确定的网络或解码故障。

公开包按白名单生成并检查凭证，不包含个人授权、设置或 data 目录。升级前请备份旧版 data，并在同一 Windows 用户下保留该目录；公开下载包不会预置任何人的 PS5 配对信息。本地个人使用副本与公开发行资产分开保存。

下载 Windows x64 ZIP 后解压运行 RelayPlayer.exe；首次连接按固定版本自动准备和校验后端组件，需要网络。public-source.zip 提供宿主源码，native-source.zip 提供修改后的原生后端及对应依赖源码；摘要见 SHA256SUMS.txt。GT7 体感实玩和主观音质听测仍需后续验证。
