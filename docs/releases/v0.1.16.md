# RelayPlayer v0.1.16

修复 PS5 待机时点击连接会黑屏约十秒后断开的问题，包含 0.1.15 的音频延迟修正。界面保持 0.1.6 布局。

- 左下角最近主机连接与连接面板的开始串流共用唤醒流程。先发现目标主机，待机时使用已有配对凭证发送网络唤醒；最多等待 60 秒，有限重试，确认主机已开机且远程游玩 TCP 服务就绪后才准备引擎并开始串流。
- 等待期间在播放器原有区域显示主机检查、唤醒、服务准备状态，不先显示黑色视频窗口。点击停止或关闭播放器即取消该次检查，旧结果不会启动新的串流。
- 搜索响应匹配已配对主机的标识与类型，发现地址变化时使用当前地址；只在成功收到视频后保存最近连接地址。不会向另一台已识别的主机发送配对唤醒凭证。UDP 发现受过滤但已保存地址的串流服务可达时保留直接连接兼容。
- 唤醒超时明确提示 PS5 的网络待机选项和网络要求，使用播放器自己的提示区域。PS5 必须启用「与互联网保持连接」及「允许通过网络启动 PS5」；完全关机无法网络唤醒。
- 主机切换电源状态时，兼容 Windows 对发现 UDP 返回的临时端口重置／拒绝错误，在既定超时内继续搜索与唤醒。
- 已连接时点击停止、关闭独立播放窗口或正常退出应用，先通过当前授权会话请求 PS5 进入待机，再清理串流，无确认弹窗。应用画质参数引起的自动重连保持主机开机；取消唤醒或连接准备不会新建会话发送待机。断网或强制结束进程时不能保证待机。
- 包含单个有界 PCM 回调缓冲、过期声音丢弃和音频配置迁移，详见 0.1.15 说明；保留 0.1.14 的窗口交接、画质设置应用、原生菜单禁用、全屏隐藏、手柄与停止清理。

验证包括真实 UDP/TCP 的待机转开机、丢失唤醒包重试、远程游玩服务延迟启动、其他主机响应隔离、发现过滤兼容、超时和停止后不接受旧结果；另有原有进程生命周期与设置迁移检查。

实机验证：开始时目标 PS5 实际处于待机（DDP 620），生产连接流程于约 0.12 秒发送唤醒，约 8.87 秒检测到已开机，约 9.93 秒开始准备组件，约 19.08 秒收到实际视频。引擎保持运行超过 60 秒，画面为 1920×1080，稳定阶段约 60 fps，最后正常停止且保存最近主机。测试使用独立授权副本，未录制屏幕或输出凭证。音频状态显示 10.667 ms 设备周期、40 ms 队列上限；这些数值不代表到耳机的总延迟。

追加实机验证：点击停止、宿主退出清理、独立播放窗口关闭后均由 DDP 确认回到待机；修改码率触发自动重连期间保持开机并恢复实际视频。Rust 测试 60 项通过、2 项忽略，协议测试 83 项通过，进程生命周期检查覆盖停止待机、退出待机及内部重连保持开机。PCM／WASAPI 检查 120147 项通过；非黑像素读取及原生界面隔离复核通过。GT7 体感实玩与主观音质仍需后续验证。

公开发行不含个人 PS5 凭证或 data。升级请先备份并保留自己的 data，在同一 Windows 用户下使用。Windows x64 ZIP 解压运行即可，首次准备固定后端组件需要网络。宿主及修改后原生后端的对应源码、许可与校验值随发行提供。
