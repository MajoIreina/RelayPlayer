# RelayPlayer v0.1.12 local candidate

修复运行状态面板多项缺少真实信息、补帧显示内部编号，以及停止连接时弹出后端休眠确认的问题。保留现有播放器布局和 0.1.11 的退出清理。

- 显卡与驱动来自当前渲染器使用的 Vulkan 设备；显示器尺寸与刷新率来自所在屏幕。没有测量时不拿保存的目标值替代。
- NR 的硬件支持与当前可用性分开报告。成功处理视频帧后才确认支持；关闭 NR、尚未验证或初始化失败分别显示。初始化失败后保留已经取得的支持证据，不将 RTX 型号或 DLL 存在当成可用证明。
- 补齐实际画面来源、采集状态、采集尺寸与帧率、测量输入码率、处理后呈现帧率、平均丢包率、累计丢失视频帧、实体手柄名称、窗口焦点和渲染提交耗时。网络往返使用连接建立时的探测结果，明确标为「连接探测往返」，不冒充实时 RTT；渲染提交耗时不冒充 GPU 全程耗时。未接入采集音频明确显示，未提供的解码耗时不虚构。
- 统一后端与宿主的字段和单位。兼容旧状态中的 Mbps 与 displayFps；实际补帧显示算法名称与倍率，D3D12 DLSS 不再显示为「5」。
- 状态超过 4 秒未更新时隐藏旧指标并提示状态更新中断；停止或切换会话不继续显示上一会话的实测数据。
- 停止连接使用专用 stop 命令，直接停止当前会话，不弹休眠确认，也不请求主机休眠。关闭原生播放窗口同样不弹后端确认。停止期间隐藏画面、静音，保留嵌入关系直至进程结束，避免再次还原独立窗口；组件无响应时最多等待 750 ms 后清理所属进程。

验证：Rust 单元与进程集成检查；独立/嵌入窗口退出、后台子进程、强制结束宿主、直接停止命令与不响应组件清理、状态字段转换和面板真实显示。实际 RTX 5080 GPU 读取显卡/驱动并成功处理合成 NR 视频帧，验证未测能力不假定支持、失败不抹去已确认硬件证据。未操作用户运行中的播放器，PS5 实际串流退出和采集卡硬件仍未实测。

本地授权与设置沿用 0.1.11；公开压缩包不含 data、账号或主机凭证。本版为本地工作区构建，未创建 Git 标签或上传 GitHub。
