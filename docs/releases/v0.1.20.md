# 0.1.20

修复实际 PS5 HDR 串流下 RTX 超分与补帧未生效的问题，整理画质设置。本版包含此前 0.1.19 本地修复版的增强状态提示与重试恢复。

- 选择“BT.2390 转 SDR”时，在超分和补帧之前执行真正的 HDR→SDR 色彩转换。原始 HDR 串流设置保留；转换缓存按源帧与设置更新，曝光、滤镜仍只在最终画面应用一次。
- 保留 HDR 直通时，明确提示 SDR 专用增强引擎不兼容。转换或增强失败时回报具体原因，不将未处理帧标为生效。
- 画质按串流输入、超分、补帧、HDR、色彩质感、画面清理、NR 排列，缩短说明；开启的补帧与 NR 默认展开。
- 运行状态的长文本、设备名称和原因自动换行，后续行随内容高度排列。

升级时先关闭旧版，将原目录下的 `data/public-connections.bin`（PS5 配对授权）、`data/public-playback.json`（画面设置）、`data/player.json`（播放器偏好）复制到新版相同位置，继续使用原 Windows 用户。保留旧版目录；Windows 发布包不包含个人数据。首次运行按需准备并校验运行组件。

2026-11-25 实机确认：PS5 1080p HDR 输入经 BT.2390 转 SDR 后，RTX 视频超分与 DLSS（Vulkan）2× 补帧同时生效，处理输出为 3840×2160。验收保留原设置“60→30 后补帧”，有效源约 30 fps，输出约 60 fps；不代表所有内容均可达到 4K 120 fps。

验证包括 65 项宿主测试、隔离进程与窗口生命周期协议、153 项原生策略检查，以及 PQ 亮度样本读回、HDR 保护、VSR／FSR／ArtCNN 与 DLSS 组合、HDR 直通后恢复和三种面板宽度下的换行。合成 HDR 输入组合测试约 120 fps；另一次 SDR 合成回归在退出清理时超时，宿主的子进程清理保护检查通过。输出帧率受源帧去重、算法耗时和显示刷新率影响。

发布附件包括 Windows x64 程序包、宿主源码、完整原生对应源码和 SHA-256 校验文件；上游署名与许可保留。
