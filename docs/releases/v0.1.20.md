# 0.1.20 本地修复版

修复实际 PS5 HDR 串流下 RTX 超分与补帧未生效的问题，整理画质设置。此轮仅更新本地版本。

- 选择“BT.2390 转 SDR”时，在超分和补帧之前执行真正的 HDR→SDR 色彩转换。原始 HDR 串流设置保留；转换缓存按源帧与设置更新，曝光、滤镜仍只在最终画面应用一次。
- 保留 HDR 直通时，明确提示 SDR 专用增强引擎不兼容。转换或增强失败时回报具体原因，不将未处理帧标为生效。
- 画质按串流输入、超分、补帧、HDR、色彩质感、画面清理、NR 排列，缩短说明；开启的补帧与 NR 默认展开。
- 运行状态的长文本、设备名称和原因自动换行，后续行随内容高度排列。

本地升级原样迁移最新旧版的 `data/public-connections.bin`、`data/public-playback.json`、`data/player.json`，继续使用原 Windows 用户下的 PS5 配对授权和画面设置。保留旧版目录，公开候选包不包含个人数据。

测试包括 HDR PQ 亮度样本读回、转换前 HDR 保护、转换后 VSR 与 DLSS 补帧组合、恢复 SDR、界面换行与隔离进程协议。真实主机验收结果另存本地验收报告；输出帧率受源帧去重、算法耗时和显示刷新率影响。
