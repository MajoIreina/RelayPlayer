# 0.1.19 本地候选版

基于 0.1.18，处理超分／补帧偶发失效后的状态识别与恢复。本轮未发布 GitHub Release。

## 改动

- 超分状态区分等待画面、实际启用、无需放大、HDR 输入不兼容、引擎失败及神经渲染已完成放大。RTX 视频超分跳过 HDR 输入时，不再显示“当前画面无需放大”。FSR／整数缩放也需确认实际执行，才显示生效。
- 超分与补帧加入重试入口，重新连接原主机并启动新的隔离渲染进程，清除旧进程内的失败锁定。重试不会请求 PS5 待机，也不改写画质和配对授权。重复点击受操作状态保护。
- 检测到超分／补帧失败后，修改所选算法、VSR 档位或补帧开关／引擎会重新连接并重建引擎。正常画质微调仍直接应用。不会在每帧或后台无限重试失败的驱动调用。
- 补帧显示实际倍率、去重后的源帧率和测得的输出帧率，便于识别 30→60 与 60→120 的差异。

## HDR 与验证范围

当前原生 RTX 视频超分路径仍只接受 SDR 输入，且位于最终色调映射之前；选择 BT.2390 转 SDR 输出不等于向超分提供 SDR 输入。需要该算法时可手动关闭串流 HDR，或保留 HDR 并选择 ArtCNN／FSR。升级不会自动更改用户的 HDR 或算法选择。

已通过宿主单元测试与隔离进程生命周期检查，覆盖失效状态、重复重试、重连不待机及设置保留。原生策略检查和合成 GPU 回归记录随本地验收保存。未复现用户真实 PS5 串流中的所有随机失效，合成 GPU 通过不代表已完成真实 PS5 端到端验证。

## 本地升级

在同一 Windows 用户下，将最新旧版中的 `data/public-connections.bin`（PS5 配对授权）、`data/public-playback.json`（画面设置）和 `data/player.json`（播放器偏好）原样复制到新版相同位置。原有 0.1.16 授权经 0.1.18 沿用至本版；保留旧目录。DPAPI 授权须由原 Windows 用户读取。

候选程序从本次提交的源码构建；公开候选包不含个人 data。宿主源码、完整原生对应源码、原生二进制覆盖包及文件清单保持一致，上游署名与许可均保留。
