# RelayPlayer v0.1.10 local candidate

保留 0.1.6 播放器布局；为公开后端接通原界面的设置与真实渲染反馈。

- 超分：实际 FSR 1、ArtCNN（清晰/降噪）、整数缩放、RTX VSR；质量、锐度、纹理恢复、1080p/1440p/2160p 处理目标接入。固定目标先处理再适配窗口。超分先于补帧，避免补帧覆盖所选算法。
- 补帧：DLSS、NVIDIA 视频补帧、光流补帧；2–4 倍、重复帧处理已接入。刷新率会限制实际倍率，状态显示具体原因。原 Warp 选项准确标为光流。
- 颜色与质感：预设及饱和度、对比度、伽马、鲜艳度、暗部、清晰度、色温、颗粒、去色带、缩放抗锯齿已连接真实 GPU 处理。NR 单次处理、输入尺寸；风格/强度可实时调整。
- 串流：分辨率、帧率、编码、最高 200 Mbps 目标、手动 HDR 修改后自动重连；色调映射、显示节奏、背景填充实时更新。码率锁定是本地目标请求锁定，不保证 PS5 实际吞吐。
- 采集：DirectShow 设备枚举与 FFmpeg 解码，尺寸/帧率/格式、范围与 HDR 元数据；帧只保留最新一张。采集视频可与网络控制配合。没有实体采集卡，未做采集硬件验证，采集音频尚未接入。
- 反馈：保存、接受、实际帧应用分开显示；执行失败不会用所选算法冒充实际算法。保留后台手柄/USB 体感修正及 WASAPI 缓冲设置。

当前模型没有 NR HUD 保护和原始色彩保留接口；自动 HDR、手动 FEC 与自动恢复码率也尚未接入。这些项在原位置明确禁用，不伪装可用。其余连接、配对与界面仍由 Relay 管理。

验证：43 项 Rust 单元检查、进程协议集成检查、固定清单安装/校验、实际 Qt 子进程与设备枚举；RTX 5080 上 GPU 像素读回检查及 FSR/ArtCNN 钩子运行、光流/DLSS/NVIDIA VFG 中间帧检查、1080p 静止 NR 测试通过。仍需用户 PS5 实际串流、声音听测、GT7 与采集卡验证。公开包不含账号、主机密钥或本地数据。
