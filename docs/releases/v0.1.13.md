# RelayPlayer v0.1.13 local candidate

保留现有播放器布局，将画面和设置统一交给 Relay，修复重复帧识别后补帧倍率自动增加的问题。

- 原生算法曾将设置倍率乘以去重系数，2× 在半速源画面下变为 4×。Relay 模式现在以去重后的源画面为基准，所选 2×、3×、4× 是上限；显示器刷新率或算法能力只能降低实际倍率，不能提高它。关闭补帧会明确设置后端为关闭。
- 在建立会话之前传入播放器保存的完整画质设置，实时修改继续走私有 stdin 通道。不再在初始化期间短暂继承原生菜单里的补帧开关与倍率。
- Relay 模式只加载视频根项，不加载原生的设置页、菜单、NR 面板、快捷键提示、加载动画、错误弹窗或统计窗口。键盘和手柄不会打开第二套设置界面。原生资源显示为 Relay Video，保留上游版权和来源说明。
- 禁用原生组件额外启动的主机发现与广播监听，主机搜索、授权和唤醒继续使用 Relay 自己的实现，移除这条触发 Windows 网络访问提示的重复路径。没有关闭防火墙、修改系统通知或加入全局放行规则。Windows 首次访问授权、已有阻止规则或管理员策略仍须由系统处理，不能承诺任意系统环境永远不显示安全提示。
- 连接错误转交现有播放器提示；主机解锁请求转交现有手柄设置中的主机解锁控件。解锁 PIN 只经私有管道发送，不持久化、不记录日志、不放入公开包。
- 保留 0.1.12 的真实状态检测、直接停止且不休眠，以及 0.1.11 的关闭窗口后所属进程清理。

验证覆盖：144 组倍率、去重、刷新率与算法上限的组合；真实原生组件在独立测试命名空间内加载视频根项，验证没有原生状态窗口、发现服务或设置快捷键，并检查启动时使用播放器指定倍率和开关。实际 GPU 上用合成运动画面验证 D3D12 DLSS 2×、3×、4× 输出帧数及插值，通过全部阶段；47 项 Rust 单元测试与进程集成测试通过。未操作用户运行中的播放器；PS5 实际串流和 Windows 实际首次防火墙授权仍需实机验证。

本地使用包迁移 0.1.12 的授权与设置，公开压缩包不包含 data 或任何个人凭证。本版为本地工作区候选构建，未创建 Git 标签或上传 GitHub。
