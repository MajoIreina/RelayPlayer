# 0.1.18

基于 0.1.17，修正待机画面中央“连接主机”按钮的行为。

## 改动

- 中央“连接主机”按钮与左下角播放按钮共用最近主机连接逻辑。点击后直接连接最近成功使用且仍存在于配对记录中的 PS5，沿用服务检查、待机唤醒和组件校验流程。
- 没有可用的最近主机记录时打开连接面板；仅有一台已配对主机的旧授权库仍可直接连接。存在多台主机且没有历史记录时由用户选择。
- 保留 0.1.17 的性能优化、曝光度及亮度调节，原生渲染组件与 0.1.17 相同。

## 下载与升级

下载 `RelayPlayer-0.1.18-windows-x64.zip`，解压至可写目录并运行 `RelayPlayer.exe`。首次准备组件需要网络，建议预留 3 GiB。

本地升级前关闭播放器并备份目标已有设置。在同一 Windows 用户下，将旧版本的 `data/public-connections.bin`（PS5 配对授权）、`data/public-playback.json`（画面设置）、`data/player.json`（播放器设置）复制至新版本相同位置。已在 0.1.17 导入的 0.1.16 原授权及画面设置可以继续沿用；新增曝光度和亮度缺省均为 0。

公开安装包和源码包不包含个人 `data`、配对密钥或账号授权。Windows DPAPI 授权仅能由原 Windows 用户解密。

## 验证与源码

宿主 63 项测试通过，2 项原有忽略；进程生命周期、控制管道阻塞与退出检查通过。已有最近主机测试覆盖重启后保留记录及移除主机后不再连接。本轮没有新增真实 PS5 串流、帧率或端到端延迟测试；0.1.17 性能与 GPU 验证范围见 [0.1.17 说明](v0.1.17.md)。

正式包从 `v0.1.18` 标签源码构建。`public-source.zip` 提供宿主源码，`native-source.zip` 提供完整原生对应源码；原生实现与 0.1.17 一致，保留其构建记录及上游许可。三个 ZIP 的摘要见 `SHA256SUMS.txt`。
